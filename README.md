# Pullback Detector V3

High-quality intraday pullback detection engine for sideways and transitional markets.

Status: architecture/skeleton stage. No production trading claims.

## Principles
- Regime first
- Location before direction
- Anatomy before signal
- Confirmation before entry
- No look-ahead
- Fail closed on invalid data
- Historical replay and live mode share the same detection engines
- No secrets committed to the repository
